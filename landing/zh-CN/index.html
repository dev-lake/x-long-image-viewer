A FEW GOOD QUESTIONS.

你可能还想知道。

支持哪些浏览器和网站？+

支持 Chrome 和 Microsoft Edge 116 及以上版本。安装后，查看器会在 x.com 和 twitter.com 的媒体图片上生效。它不会接管其他网站的图片。

需要额外注册或登录吗？+

扩展无需单独注册或登录。安装后刷新已经打开的 X / Twitter 页面，再点击媒体图片即可使用。访问 X 本身是否需要登录，由 X 的访问规则决定。

识别文字需要联网或上传图片吗？+

OCR 引擎和语言模型随扩展打包，识别在设备本地完成，不调用在线识别服务。浏览器仍需要从 X 的图片服务器获取你选中的图片。识别结果只暂存在页面内存中，刷新页面后清除。

图片里的所有文字都能准确识别吗？+

目前支持英文和简体中文。清晰的印刷文字效果较好，过小、旋转、手写或复杂排版的文字可能有误差；超过 4000 万像素的图片不会进行识别。复制后建议核对原文。

安装后没有生效，怎么办？+

先确认扩展已启用，再刷新已经打开的 X / Twitter 标签页。升级或重新加载扩展后，也需要刷新页面。如果问题依然存在，可以到 GitHub 提交反馈。

液态玻璃在不同设备上都能使用吗？+

图片折射在设备本地完成。如果无法使用折射效果，会自动显示磨砂玻璃，仍可照常看图和选中文字。
