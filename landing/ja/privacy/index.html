プライバシーポリシー

施行日：2026年11月1日

X Long Image Viewer は、X / Twitter の縦長画像を読みやすくするブラウザ拡張機能です。文字認識はあなたの端末上で処理されます。画像や認識した文字が、開発者や OCR サービスにアップロードされることはありません。

データの取り扱い

この拡張機能は、個人情報やページの内容を開発者に送信せず、販売やアクセス解析にも利用しません。以下の情報を解析目的で収集したり、開発者に送信したりすることはありません。

  • 個人を特定できる情報と認証情報
  • 閲覧履歴と位置情報
  • ユーザーの行動分析データ

画像表示と文字認識

拡張機能のコンテンツスクリプトは、x.com と twitter.com でのみ動作します。投稿の画像をクリックすると、現在のページから画像の URL を読み取り、同じブラウザタブ内でビューアを開きます。

ブラウザは、画像の表示や操作に応じた文字認識のため、選択した画像を X / Twitter の画像サーバーから取得します。Liquid Glass を有効にすると、同じ画像を再取得し、端末上で一時的な描画テクスチャを作成する場合があります。ページの撮影や、画像・描画結果のアップロードは行いません。画像の URL が開発者や OCR サービスに送信されることはありません。

「テキストを選択」を選んだときにのみ、画像内の英語と簡体字中国語を端末上で認識します。認識結果は現在のページのメモリに最大8枚分だけ一時保存され、ページを再読み込みすると消去されます。文字がクリップボードに書き込まれるのは、あなたがコピー操作を行ったときだけです。 文字選択ガイドを表示しただけでは認識を開始しません。

ブラウザ内に保存する設定

拡張機能はブラウザのローカルストレージに、個人情報を含まないビューアの設定と案内の表示状態を保存します。ツールバーのスタイル、ツールバーと全体表示の位置、文字選択ガイドを閉じたかどうか、ビューアを開いた回数、評価依頼を閉じたか、後回しにしたか、評価したかなどが含まれます。

これらの情報は、表示設定を記憶し、同じ案内の繰り返しを避けるためだけに使用します。ブラウザ内に保存され、開発者には送信されません。

権限の使用目的

  • x.com と twitter.com：投稿画像のクリックを検知し、ビューアを表示します。
  • pbs.twimg.com：選択した画像を取得し、表示、任意の文字認識、Liquid Glass 描画を端末上で処理します。
  • offscreen：ローカルの拡張機能ドキュメントで、同梱の文字認識エンジンを実行します。
  • storage：スタイルと位置の設定、文字選択ガイドの非表示状態、評価依頼の状態を保存します。

外部サービスと本ウェブサイト

この拡張機能はバックエンドサーバーを運用せず、アクセス解析や外部から読み込んだコードの実行も行いません。文字認識エンジンとモデルは拡張機能に同梱されています。

本ランディングページには、アクセス解析スクリプトや広告追跡スクリプトを追加していません。サイトへのアクセス時には、ページを配信するために必要な通信が発生します。これは、拡張機能がブラウザ内で画像を処理する仕組みとは別のものです。ウェブサイトでは、手動で選んだ表示言語をブラウザのローカルストレージに保存し、次回のアクセス時にも使用します。

利用範囲

ユーザーデータの使用は、用途制限（Limited Use）の要件を含む Chrome ウェブストアのユーザーデータポリシーに従います。選択したウェブサイトの画像と認識した文字は、ここに記載した画像表示および文字選択機能の提供にのみ使用します。

お問い合わせとフィードバック

プライバシーに関するご質問は、拡張機能ストアに記載された公開元のサポート窓口、または GitHub の問題報告 ↗をご利用ください。公開の報告には、個人情報や非公開の画像を含めないでください。
