プライバシーポリシー

A FEW GOOD QUESTIONS.

気になることを、先に。

対応するブラウザとサイトは？+

Chrome と Microsoft Edge のバージョン 116 以降に対応しています。インストール後、x.com と twitter.com のメディア画像で動作します。他のサイトの画像には適用されません。

別途アカウント登録やログインは必要ですか？+

拡張機能用の登録やログインは不要です。追加後、すでに開いている X / Twitter のタブを再読み込みして、画像をクリックしてください。X 自体へのログインが必要かどうかは、X のアクセス条件によります。

文字認識には通信や画像のアップロードが必要ですか？+

OCR エンジンと言語モデルは拡張機能に同梱され、認識は端末内で行われます。オンラインの文字認識サービスは利用しません。ただし、選択した画像を X の画像サーバーから取得するための通信は必要です。認識結果はページ内のメモリに一時保存され、再読み込みで消去されます。

どんな文字でも正確に認識できますか？+

現在は英語と簡体字中国語に対応しています。鮮明な印刷文字の認識に適していますが、小さい文字、回転した文字、手書き、複雑なレイアウトでは誤りが生じる場合があります。4,000 万画素を超える画像は認識しません。コピー後は原文と照合してください。

インストール後に動作しない場合は？+

拡張機能が有効になっていることを確認し、開いている X / Twitter のタブを再読み込みしてください。拡張機能を更新・再読み込みした場合も同様です。解決しない場合は、GitHub でご報告ください。

Liquid Glass はどの端末でも使えますか？+

画像の屈折処理は端末上で行います。屈折効果を利用できない場合は、すりガラス表示に切り替わります。画像の閲覧や文字選択は引き続き利用できます。
