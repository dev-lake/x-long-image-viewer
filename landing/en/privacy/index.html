Privacy policy

Effective date: November 1, 2026

X Long Image Viewer is a browser extension for viewing long images on X / Twitter. Text recognition runs on your device. Images and recognized text are not uploaded to the developer or an OCR service.

How we handle data

The extension does not send personal information or page content to the developer, sell this information, or use it for analytics. It does not collect the following for analytics or send it to the developer:

  • Personally identifiable information and authentication information
  • Browsing history and location data
  • User activity analytics

Image viewing and text recognition

The extension’s content script runs only on x.com and twitter.com. When you click a media image, the extension reads its URL from the current page and opens a viewer inside the browser tab.

Your browser requests the selected image from X / Twitter’s image host to display it or recognize text at your request. When Liquid Glass is enabled, it may request that image again to create a temporary rendering texture on your device; it does not capture the page or upload images or rendered pixels. The image URL is not sent to the extension developer or an OCR service.

Only when you choose “Select text” does the extension recognize English and Simplified Chinese on your device. Results are cached temporarily in the current page’s memory for up to eight images and cleared when the page reloads. Text is written to the clipboard only when you choose to copy it. Showing the text selection guide alone does not start recognition.

Settings stored in your browser

The extension uses local browser storage for non-personal viewer preferences and prompt state: toolbar style, toolbar and overview positions, whether the text selection guide has been dismissed, viewer open count, and whether you dismissed, deferred, or completed a rating prompt.

This information is used only to remember your interface preferences and avoid repeated prompts. It stays in your browser and is not transmitted to the developer.

What the permissions are for

  • x.com and twitter.com: detect media-image clicks and display the viewer.
  • pbs.twimg.com: retrieve the selected image for display and local processing, including optional text recognition and Liquid Glass rendering.
  • offscreen: run the bundled recognition engine in a local extension document.
  • storage: save viewer style and position preferences, text-guide dismissal, and rating-prompt state.

Remote services and this website

The extension does not operate a backend server, use analytics, or include remotely executed code. The recognition engine and models are bundled with the extension.

This landing page has no added analytics or advertising-tracking scripts. Visiting the website creates the network requests needed to serve the page; this is separate from how the extension processes images in your browser. The website remembers the display language you manually choose in your browser’s local storage so it can use that language on your next visit.

Limited use

The extension’s use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Selected website images and their recognized text are used only to provide the image-viewing and text-selection features described here.

Contact and feedback

For privacy questions, use the publisher’s support contact in the browser extension store, or report an issue on GitHub ↗. Avoid including personal information or private images in public reports.
