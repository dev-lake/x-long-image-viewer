# X Long Image Viewer 2.1.0

Prepared: 2026-11-01. Publishing copy for the next store submission; this file does not indicate that the release has been published.

## 简体中文

- 新增 iOS 液态玻璃工具栏，可在设置中与经典样式切换。
- 工具栏位置统一放入设置，样式与顶部/底部位置自动保存。
- 点击缩放百分比，按 50% → 80% → 100% 三档循环切换。
- 新增首次文字选中引导，并可从设置中随时重新查看。
- 图片折射与文字识别均在本地完成；引导本身不会启动识别。液态玻璃不可用时自动使用磨砂玻璃效果。

## English

- Added an iOS Liquid Glass toolbar style, selectable alongside Classic in settings.
- Grouped toolbar style and top/bottom position in settings, with saved preferences.
- Click the zoom percentage to cycle through 50%, 80%, and 100%.
- Added a first-use text selection guide, available again from settings.
- Image refraction and text recognition run locally. The guide does not start recognition; glass rendering falls back gracefully when unavailable.

## 日本語

- 設定からクラシックと切り替えられる iOS Liquid Glass ツールバーを追加しました。
- ツールバーのスタイルと上下の配置を設定にまとめ、選択内容を保存します。
- 倍率を押すたびに 50% → 80% → 100% の順に切り替えられます。
- 初回の文字選択ガイドを追加し、設定からいつでも開き直せます。
- 画像の屈折と文字認識は端末上で処理します。ガイドの表示だけでは認識を開始しません。Liquid Glass を利用できない場合はすりガラス表示に戻ります。

## Português do Brasil

- Adicionado o estilo Liquid Glass do iOS, disponível junto ao Clássico nas configurações.
- Estilo e posição superior/inferior da barra reunidos nas configurações, com preferências salvas.
- Clique na porcentagem para alternar entre 50%, 80% e 100%.
- Novo guia inicial de seleção de texto, que pode ser reaberto nas configurações.
- A refração da imagem e o reconhecimento de texto são locais. O guia não inicia o reconhecimento; há uma alternativa de vidro fosco quando necessário.
