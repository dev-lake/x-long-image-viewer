# Local OCR components

- Tesseract.js: https://github.com/naptha/tesseract.js — Apache-2.0. See TESSERACT-LICENSE.md.
- Tesseract.js-core: https://github.com/naptha/tesseract.js-core — Apache-2.0. See CORE-LICENSE.
- English and Simplified Chinese model packages: https://github.com/naptha/tessdata, @tesseract.js-data/eng and @tesseract.js-data/chi_sim 1.0.0. Package metadata declares MIT; trained model files originate from the Tesseract tessdata project (https://github.com/tesseract-ocr/tessdata, Apache-2.0).

All recognition scripts, WASM and model files are bundled. No executable code is downloaded at runtime.
